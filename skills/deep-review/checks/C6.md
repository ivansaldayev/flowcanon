# C6 — CLAUDE.md Compliance

For each changed file, find all CLAUDE.md files in the chain from file to root — the closest directory first, then each parent, then the repository root, e.g. `<project>/src/<area>/CLAUDE.md` → `<project>/CLAUDE.md` → `./CLAUDE.md`.

Priority: closest > parent > root. Check code against rules in each. Flag violations with reference to specific CLAUDE.md and rule.

Rule files a CLAUDE.md marks as mandatory (a coding-rules file it links as required reading) are part of that CLAUDE.md's rule set — read them and check code against them.
