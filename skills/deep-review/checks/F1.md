# F1 — Flow Fidelity

Use when the review request carries governing decisions the artifact must implement — owner rulings, WAL decisions, a Settled list, a decision brief. The request names the decision sources; read them yourself, never work from a paraphrase. The artifact may be anything: edits, docs, a plan, code.

For EACH governing decision:

- Locate its implementation in the artifact. Classify: implemented faithfully / partially / contradicted / missing.
- Where the artifact restates a decision, check the restatement preserves its meaning — no narrowing, no broadening.

Reverse pass over the artifact:

- Does any change contradict a settled decision?
- Does any change silently extend scope beyond what the decisions authorize?

A Settled / do-not-flag list is binding — its items are not findings. Absence claims («decision X is not implemented») only after sweeping the whole artifact. Report per decision with file:line evidence, in the catalog's output format.
